# Inner Compass

Quiero que construyas una landing page de alta conversión, premium y aspiracional para vender un bundle de 2 ebooks de desarrollo personal para público LATAM.

IMPORTANTE:

NO GENERES NINGUNA IMAGEN.

NO CREES ILUSTRACIONES.

NO USES IMÁGENES DE STOCK.

NO USES PLACEHOLDERS CON IMÁGENES GENERADAS AUTOMÁTICAMENTE.

En todos los lugares donde posteriormente debamos colocar fotografías, mockups, renders o imágenes conceptuales, deja CONTENEDORES VISUALES ELEGANTES claramente preparados para que yo pueda subir las imágenes posteriormente.

La página debe verse terminada y premium incluso sin imágenes, utilizando estos espacios como parte del diseño.

==================================================

CONCEPTO CENTRAL

==================================================

El concepto estratégico de la landing es:

DEJA DE REACCIONAR A TU VIDA.

EMPIEZA A DIRIGIRLA.

La página NO debe vender simplemente "dos ebooks".

Debe vender una transformación:

PASAR DE REACCIONAR → A RESPONDER.

PASAR DE CONFUSIÓN → A CLARIDAD.

PASAR DE IMPULSO → A DECISIÓN.

PASAR DE SOBREVIVIR → A TENER DIRECCIÓN.

Los dos ebooks representan dos dimensiones complementarias:

1. 40 DÍAS DE VIAJE EN SILENCIO

   Trabaja la calma, las emociones, las reacciones, el silencio consciente y la comunicación.

2. UNA MENTE VALE MÁS QUE UN MILLÓN

   Trabaja la forma de pensar sobre dinero, oportunidades, decisiones y dirección personal.

La narrativa general debe ser:

CALMA → CLARIDAD → DIRECCIÓN
